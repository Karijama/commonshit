# Local Qwen 3.5 9B: multi-view CAD pose estimation

Проверка предобученной мультимодальной модели без дообучения.
GT используется для отбора ракурсов и последующей оценки, поза объекта модели не передаётся.
Камеры на первом этапе считаются известными.

Код, протокол, команды запуска и разбор MV-SAM3D:
[experiments/vlm_pose/README.md](experiments/vlm_pose/README.md).

Содержимое:
- `select_views.py`: отбор 2–3 ракурсов для каждого CAD-экземпляра;
- `run_qwen.py`: CAD-превью с локальными осями и запрос к локальному Ollama;
- `evaluate_pose.py`: независимая оценка внешнего прогноза по GT;
- `test_*.py`: тесты геометрии, ошибок позы и калибровки после resize.

Датасет scannet5 и веса модели хранятся отдельно от репозитория.
Инференс Qwen и MV-SAM3D в текущей среде не выполнялся.
Подготовка данных проверена на пяти сценах: 47 экземпляров, 141 кадр в буквальном
top-3; 133 кадра в дополнительном режиме с приблизительной видимостью и углом 15°.
В последнем режиме некоторым экземплярам доступно меньше двух ракурсов —
они не проходят минимальное требование адаптера и должны быть учтены в coverage.
